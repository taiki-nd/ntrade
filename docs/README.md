# ntrade: ロジック戦略による FX 自動売買システム 設計ドキュメント

## プロジェクト概要
主要通貨ペア（USD/JPY, EUR/USD など）と CFD を対象に、Rust で書いたロジック戦略で自動売買を行うローカル運用型のトレードシステムです。
手元で常駐する **Rust コアエンジン（Tokio + Axum）** と、操作・監視を行う **Next.js 管理画面** で構成され、ブローカー接続・注文執行には **cTrader Open API** を使います。

2026-10-22 に LLM による判断をやめ、ロジック戦略に切り替えました（[04](./04_roadmap_and_tech_stack.md) の「方針転換」）。

## 設計の原則
1. **バックテストと本番で同じコードを通す**: 戦略（`strategy::build`）とリスクチェック（`guard::evaluate`）は共通。違うのは足の取得元と注文の出し先だけ。
2. **戦略は確定足だけを見る**: 未確定の足・未来の足は渡さない。本番は再起動のたびに戦略を作り直すので、判断は渡された足だけから決める。
3. **迷ったら不利に倒す**: バックテストの約定は、1本の足の中で順序が分からないときに不利な側を採る（[06](./06_backtest.md)）。
4. **新しい戦略はドライランから**: 本番のデプロイは既定でドライラン（発注せずシグナルを記録）。シグナルログで挙動を確かめてから発注に切り替える。
