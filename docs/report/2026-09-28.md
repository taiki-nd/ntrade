## 5. 改善候補

1. **SL の最小距離を決める**：ATR などに連動させる。約定価格でSLまでの距離を再計算し、足りなければ発注を取り消すか、SLを広げる。
2. **損切り後のクールダウン**：同じペア・同じ方向での再エントリーを一定時間（例：30分）止める。
3. **日中の値幅による制限**：値幅が平均を超えたら、その方向の追いかけ売買の確信度に上限をかける。
4. **相関のガード**：ドルの向きが逆になるポジションの同時保有を検出する。
5. **ローソク足データの取り込み**：`bars_history` を 9/15 以降も更新する。事後検証（SL後にTPへ届いたか等）ができるようになる。→ 実施済み（6章）

### 6.2 「実体で抜けたら無効」と「ヒゲで刺さるSL」の不一致

プロンプト（`src/strategy/prompt.rs`）では、損切り位置を「どこを**実体で**抜けたら相場観が間違いになるか」と定義しています。一方、ブローカーに置くSLは**ヒゲが触れた時点**で約定します。LLMが想定している無効化条件と、実際の執行条件が一致していません。

- 終値ベースで決済すると、負けたときの損失は大きくなります（#6・#7）。急変に備えて、別途、広めのハードSLが必要です。
- 7件・1日分だけの結果なので、統計的な根拠にはなりません。3ヶ月分のリプレイで検証する必要があります。
- 試算に使ったのは Bid ベースの5M足です。約定価格とのずれは考慮していません。
